### 🚀 Featured Projects

#### 🌦️ AETHER-BUST — AI Forecast Bust Detection
An AI system designed to predict where and when medium-range weather forecasts may fail.

- Hybrid U-Net + ConvLSTM deep-learning architecture.
- Trained on ERA5/GFS data covering 2019–2022.
- Integrated Gradients for model explainability.
- FastAPI backend and interactive React map dashboard.

**Tech:** Python · PyTorch · FastAPI · React · MongoDB · Docker

[GitHub Repository](YOUR_AETHER_BUST_REPO_URL)

#### 📚 SAGE AI — Academic Super-Assistant
An AI-powered study platform that transforms course materials into interactive learning experiences.

- RAG-based chat over uploaded PDFs with page-level citations.
- Knowledge graphs and spaced-repetition flashcards.
- Audio summaries and real-time quiz battles.
- Learning analytics, XP, and streak tracking.

**Tech:** Python · FastAPI · React · Supabase · pgvector · Gemini

[GitHub Repository](YOUR_SAGE_REPO_URL)

#### 🧭 NavAssist — Offline Navigation Aid
An assistive navigation application designed for visually impaired users.

- In-browser object detection and local scene understanding.
- Clear, Caution, and Danger proximity levels.
- Voice alerts, voice commands, and haptic feedback.

**Tech:** Next.js · React · TensorFlow.js · SQLite

[Live Demo](https://navi-assistant.vercel.app)

[GitHub Repository](YOUR_NAVASSIST_REPO_URL)

#### 🛡️ Spam Classifier Ensemble
A machine-learning spam detector combining five classification models.

- Naive Bayes, SVM, Random Forest, Logistic Regression, and Decision Tree.
- Voting-based message classification.
- Batch processing and feedback-based retraining.

**Tech:** Python · Scikit-learn · TF-IDF
